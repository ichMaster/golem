Golem · direction 2a · Clay and stone · full set

A clay worker in a stone workshop

Golem is shaped from clay and woken by a written word — the agent's program. Its forehead glyph burns violet whenever it acts. The board is a stone tray under a warm lamp; blocks are carved sandstone; goals are bronze rune circles that ignite when a block settles. Violet is reserved for “something the word did”: Golem, a lit rune, a placed block, the current level. Everything else stays in warm, low-chroma stone, so the eye finds the action first.

04

Motion specs

Triggers are differences between the last two states the server sent — the page never decides legality. Rule one: input never waits. A key is sent the moment it is pressed; when a new state arrives mid-animation, the running tween snaps to its end in one frame and the new one starts from there. Easing curves are CSS-style so the same values drive canvas tweens and HTML panels.
