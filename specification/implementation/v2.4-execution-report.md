## Design notes

- **The phase was added mid-version at the owner's request.** It became v2.4, and the swap prototype
  moved to v2.5.
- **Frames.** They are the first step toward the replays of v5.3: a run returns the core's map after every
  move, and the page only plays them back.
- **The new routes are owner routes for the screen.** The `golem` CLI has no command for them, and the
  agent's only tool from v6 is that CLI.
- **They read programs only from `GOLEM_PROGRAMS_DIR`, by name.** v5.1's `Host` check and the framing
  headers (v2.2 review #4) will cover them as well.
- **Spike R1 now reaches the server.** A pathological program placed in `programs/` could hold one worker
  thread of the server. The folder is the owner's own, and the owner decides R1 before v4.1.
