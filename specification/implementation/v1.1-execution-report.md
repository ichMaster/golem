### GOLEM-002: The level parser and its validation
**Status:** completed · **Commit:** 01ada98 · **GitHub:** #2
**Gates:** [x] lint · [x] tests (26) · [x] CI · [ ] determinism (n/a)
**Manual (owner):** none

- `Cell` is `(row, column)` from 0. `LevelError` carries `level_id`, `line` and `column`, counted from 1 in
  the file's own lines.
- The closed-map check is a breadth-first flood fill from the robot in the order N, E, S, W, so the cell
  it reports is the same on every run.
- ARCHITECTURE.md §World and rules gained the cell convention and the error position rule (contract).
