## Design notes

The prototype confirmed the swap design, with one correction and one finding.

**Confirmed:**
- **`memory` already belonged to the run.** It is a local of the sandbox's set-up chunk, and every program
  environment points to it, so a swap needed only a second `load` in the same runtime.
- **The counter carries over** because it lives in the driver chunk's closure. A swap hands that closure
  the new chunk instead of executing the chunk again.
- **`coroutine.close` makes the old coroutine dead.** Resuming it answers `cannot resume dead coroutine`.
- **The count hook must be put on each new coroutine.** With the counter kept, the second program gets only
  the rest of the budget.
- **The world and the step count carry over.** The frames continue across the swap with no gap.
- **No sandbox change was needed.** Neither program reaches the driver, `coroutine`, `debug` or `_G`.

**Corrected:**
- **The memory cap inside a program is an ordinary Lua error.** The issue assumed that a swap would be
  refused after `not enough memory`. In fact, a program that runs into the cap inside its coroutine ends
  on an ordinary Lua error with that text, and the runtime stays usable: a swap after it solved the level
  in the prototype.
- **Only a memory error that escapes into Python breaks the run.** So do the driver's own failures
  (`internal`).
- ARCHITECTURE's new "When a swap is allowed" paragraph states this.

**Found (pre-existing since v2.3, for the v2.5 code review):**
- **A program text larger than the Lua memory cap aborts the whole process with a Lua panic** (`PANIC:
  unprotected error in call to Lua API (not enough memory)`).
- **The cause:** lupa pushes the text into Lua before its protected call, and Lua aborts on a memory error
  there.
- **It was reproduced on v2.4.0's code.** With the default 64 MiB cap, it needs a program file over about
  64 MiB.
- **Who can reach it today:** only the owner's own files (`golem-local`, the server's `programs/` folder).
- **From v5.1** the agent sends program text to the server.
- **It is outside the swap's scope**, so it goes to the v2.5 review rather than into GOLEM-027.
