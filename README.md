# golem

Sokoban-style sandbox where an AI agent writes, runs, monitors and rewrites its own Lua program to drive a robot through puzzle levels.

Status: v1, the game core (the level format, the rules, save and replay), is built; v2, the game for a human, is next. See the specification: [VISION.md](specification/VISION.md), [ARCHITECTURE.md](specification/ARCHITECTURE.md) and [ROADMAP.md](specification/ROADMAP.md) (the phased plan). The original concept is in [concept.en.md](specification/concept.en.md).
